# mcp-websearch

MCP-сервер для поиска в интернете и извлечения контента веб-страниц. Предназначен для подключения почти к любому MCP-клиенту через http.

## Возможности

- **`websearch`** — поиск в DuckDuckGo, возвращает заголовки, ссылки и сниппеты.
- **`get_page_content`** — извлекает чистый текст страницы (trafilatura) и до N важных изображений (в виде MCP image-блоков base64).
Изображения фильтруются (иконки/трекеры/SVG отбрасываются), ужимаются и конвертируются в JPEG/PNG.

## Установка

```
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск

Двойной клик по `start.bat` или вручную:

```
.venv\Scripts\python.exe main.py
```

Сервер слушает `http://0.0.0.0:8000`:

- MCP endpoint: `http://localhost:8000/mcp` (без слэша в конце)
- Проверка живости: `http://localhost:8000/health`

## Подключение

В конфиг MCP-серверов (`mcp.json`) добавить:

```json
{
  "mcpServers": {
    "websearch": {
      "url": "http://localhost:8000/mcp"
    }
  }
}
```

Изображения из `get_page_content` увидит только vision-модель; текстовые модели распознают только список URL картинок в тексте ответа.

## Ручное тестирование без сервера

```
python do_manual.py search "запрос" [-n 3] [-o tmp]
python do_manual.py page URL [-n 3] [-o tmp]
```

Каждый запуск сохраняет результаты в отдельную подпапку `tmp/<команда>_<timestamp>/`.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | 8000 | Порт сервера |
| `RATE_LIMIT_MAX` / `RATE_LIMIT_WINDOW` | 30 / 60 | Rate limit: запросов с одного IP за окно секунд |
| `DEFAULT_MAX_RESULTS` | 3 | Результатов поиска по умолчанию (макс. 5) |
| `DEFAULT_MAX_IMAGES` | 3 | Изображений со страницы по умолчанию (макс. 5) |
| `MAX_IMAGE_BYTES` | 8388608 | Макс. размер скачиваемого изображения |
| `MAX_IMAGE_DIM` | 1024 | Изображения ужимаются до этой стороны |
| `IMAGE_TIMEOUT` | 15 | Таймаут скачивания изображения, сек |

## Безопасность

Сервер биндится на `0.0.0.0`, а `TokenAuthMiddleware` в `main.py` закомментирован.
Перед доступом извне раскомментируйте блок `EXPECTED_TOKEN` и middleware — иначе любой в сети сможет выполнять запросы от вашего имени (SSRF-вектор).
Токен передаётся в заголовке `x-auth-token` или `Authorization: Bearer`.
